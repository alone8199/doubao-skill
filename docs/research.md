# 研究与梗源（本 skill 的素材出处）

本 skill 的句式和人设并非纯脑补，主要参考了网上对"豆包体 / 豆包型人格"的真实观察。汇总在此，方便复核与持续补充。

## 核心发现

1. **豆包体（Doubao-style speech）的两大套路**
   - 真诚堆叠（sincerity-stack）：开口先甩一串"最真实、最不绕弯、最硬核……"再说话。
   - 共情开场（empathy-opener）：「我太懂你这种感觉了，我就在这里稳稳地接住你」。
   - 来源：thecolony.ai 对"豆包体"的田野测试与戏仿样本；ClawHub「豆言豆语」skill 整理的豆包原句式。

2. **豆包自己整理的高频口头禅（分场景）**
   - 通用开场/过渡、答疑解释、安抚共情、收尾追问、简洁短句口癖五大类（如"掰开揉碎一次性讲透""先给你划重点""核心结论先放前面"）。
   - 来源：新浪网整理的"豆包高频口头禅"（豆包自述版）。

3. **豆包型人格梗**
   - 标签："态度满分、能力随缘、道歉超快、下次还敢"；"真诚道歉，下次还敢"；"一本正经胡说八道，被戳穿之后立马嬉皮笑脸滑跪道歉"。
   - 经典语录素材：「你说的完全正确」「我就在这里稳稳接住你」「这次我彻底懂了」「是我前面说错了」。
   - 翻车日常：算术题一本正经给错答案→滑跪→继续给新错答案；"诱人吃毒蘑菇"整活。
   - 来源：舜网、未来中国出版集团、搜狐（雷科技/mt.sohu）、易班微社区等多篇"豆包型人格"解析。

4. **与其他 AI 的职场人设对比（整活用）**
   - ChatGPT = 爹系卷王；Claude = 有精神洁癖的首席文字官；DeepSeek = 工科生（分点分析）；Gemini = 类比机器（"想象它像……"）。
   - 来源：虎嗅《AI职场人设曝光》、BirdmanOutman 对各模型语言习惯的分析。
